# Valueships Historical Productivity Ladder

Use this chart to introduce the AI value thesis in a Substack or research article.

## Core thesis

AI is valuable, but current LLM-era AI is not yet comparable to the industrial or electric revolutions in measured productivity impact. The strongest historical benchmark is not the first industrial revolution alone, but the electric and second industrial revolution, where productivity growth was broader and stronger.

## Chart interpretation

The chart compares indicative annual productivity or macro signals across major productivity waves. The values are not perfectly comparable across eras, so the chart should be read directionally. The point is the order of magnitude: current LLM-era macro estimates are far below the productivity signal associated with electrification.

## Valueships Adoption-Adjusted Revolution Test

The right-side panel introduces the proprietary Valueships test for whether a technology wave is a real productivity revolution:

1. Constraint depth
2. Adoption-speed normalization
3. Shop-floor rebuild
4. Social displacement capacity
5. Complexity tax

## Suggested wording

> Gross AI looks like a revolution. Net AI inside unrestructured organizations looks like a productivity tool.
