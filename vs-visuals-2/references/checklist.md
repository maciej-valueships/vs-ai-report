# Valueships Pre-Delivery Checklist

Run this before delivering any Valueships-branded asset. Five minutes of checking now saves an off-brand asset from ending up on a client deck.

## The "is it on-brand?" five-second test

Close your eyes. Open them. Look at the asset for one second. Then close again.

What do you remember?

- ✅ **You remember pink.** It dominated. The brand carried.
- ❌ You remember a color that isn't brand pink (red, magenta, salmon, orange, blue). Fix the color.
- ❌ You don't remember any color. There isn't enough pink. Add more.
- ❌ You remember a color that's also pink but not the brand pink. Check the hex — it must be `#FF005E`.

## Detailed checklist

### Colors
- [ ] Primary pink is exactly `#FF005E` (not a shade close to it)
- [ ] Pink dominates — visible in at least 3 distinct elements
- [ ] Dark blue (if used) is `#0F155B` and appears once or twice at most (9:1 ratio respected)
- [ ] No off-brand colors anywhere: no green, no orange, no purple, no teal, no yellow
- [ ] Background is white (or approved pink for hero covers only)
- [ ] Body text is black on white — never pink

### Typography
- [ ] Headers are Lato (any weight as appropriate for hierarchy)
- [ ] Body copy is Roboto Regular
- [ ] No other typefaces appear anywhere
- [ ] H1-size headings use Lato Medium (not Bold) — size carries emphasis
- [ ] Line height is 120–140% — not cramped, not airy
- [ ] All-caps used only for short labels (kickers, button labels)
- [ ] Captions and metadata in Roboto 12pt in ink-soft grey

### Logo
- [ ] Logo is present
- [ ] Logo is the correct version for the background (full-color for white, white for pink/dark, achromatic when appropriate)
- [ ] Logo proportions are untouched (not stretched, rotated, or distorted)
- [ ] Protective field is respected — no elements crowding within `0.5x` of any side
- [ ] Logo is at a discreet scale — not competing with primary content
- [ ] Arrow color is brand pink (not red, not magenta)

### Key visual
- [ ] Flowing-line key visual is present in at least one corner
- [ ] Key visual is in brand pink (or white if on pink background)
- [ ] Key visual is thin stroke (0.5–1.5pt), not thick
- [ ] Key visual is cropped — extends past canvas edge
- [ ] Key visual is anchored to a corner or edge, not centered
- [ ] Key visual sits behind content (lowest z-order)
- [ ] Key visual doesn't cover or interfere with text

### Layout
- [ ] Generous white space — no element is suffocating
- [ ] One clear hero moment — eye knows where to land first
- [ ] Visual hierarchy is obvious: hero → headline → supporting elements → footer
- [ ] Alignment is consistent — elements share grid lines
- [ ] Margins are at least 5% of canvas width on all sides

### Content
- [ ] Spelling and grammar checked
- [ ] No placeholder text ("Lorem ipsum", "TBD", "[insert here]")
- [ ] Numbers are accurate and verified
- [ ] Quoted text is attributed correctly
- [ ] Sensitive data (real client names, internal figures) is redacted or anonymized as appropriate

### Format-specific
- [ ] **Social (LinkedIn / Twitter):** Square 1:1 or vertical 4:5, exported at 1800×1800 or 1200×1500 minimum
- [ ] **Deck slide:** 16:9 at 1920×1080, safe margins from the edge for projector cropping
- [ ] **Document:** A4 or US Letter, margins ≥ 20mm, page numbers, footer with logo
- [ ] **Web hero:** Responsive, tested at 1920px and 375px widths
- [ ] **Email:** Inline styles, table-based layout, system-font fallbacks

### File hygiene
- [ ] Filename is descriptive (e.g. `valueships_pricing_audit_70k_linkedin.png`, not `untitled-1.png`)
- [ ] Exported at correct resolution for the platform
- [ ] File size is reasonable (PNG under 2MB for LinkedIn, under 500KB for email)
- [ ] No personal/test metadata embedded in the file

## When something fails the checklist

Don't panic. Most fails are fixable in seconds:

- **Wrong shade of pink** → swap hex to `#FF005E`
- **Wrong font** → reapply Lato or Roboto
- **Missing key visual** → add a pink line in the top-left corner
- **Logo too big** → scale down
- **Body text in pink** → switch to black, move pink to the headline or accent
- **Off-brand accent color** → replace with pink or dark blue

The fixes are always small. Catch them before the asset ships.

## When the checklist genuinely doesn't apply

Some asset types (e.g. an internal-only spreadsheet, a quick whiteboard sketch, a screenshot annotation) don't need full brand compliance. Use judgment. The checklist is for things going to clients, prospects, the public, or LinkedIn.
